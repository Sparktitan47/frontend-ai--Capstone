# Frontend AI Capstone

## Overview

This repository is my development workspace for learning frontend engineering and AI-assisted development. It will grow as I work through the FE-01 assignment and future learning exercises. The repository is currently a starting point; no application features are documented as complete.

## Learning objectives

- Practice the foundations of frontend engineering and organize a maintainable project.
- Learn to use AI tools as part of a thoughtful development workflow.
- Build familiarity with documenting, reviewing, and improving code.
- Develop good habits for handling configuration and sensitive information.

## Technology stack

No application framework, language, or package manager has been selected for this workspace yet. The stack can be documented here when project tools are chosen.

## Prerequisites

- Git, to inspect and manage the repository history.
- A code editor of your choice.
- Any language runtimes or tools required by a future project setup; none are currently required to read these files.

## Setup

1. Clone the repository, or open your existing project copy.
2. Open the project root in your code editor.
3. Review this README and `AGENTS.md` before making changes.

There are no packages to install or application commands to run at this stage.

## Development conventions

- Prefer clear, readable, maintainable code and explain non-obvious choices.
- Inspect existing files before changing them, and keep changes focused on the task.
- Do not add passwords, API keys, or other secrets to the repository. Use local environment configuration and keep secret-bearing environment files untracked.
- Use Conventional Commits when writing Git commit messages.
- Review the diff before considering a change complete.
