# Project purpose

This repository is a learning workspace for frontend engineering and AI-assisted development, beginning with the FE-01: Frontend AI Engineering Setup assignment. Do not assume application features or tooling exist unless they are present in the repository.

# Coding standards

- Write readable, maintainable code with clear names and a consistent style.
- Keep changes focused and avoid adding unnecessary files or dependencies.
- Follow the conventions already used by the project when they exist.
- Explain significant changes, including what changed and why.
- Inspect the existing files and relevant project structure before modifying anything.
- Never commit passwords, API keys, tokens, private credentials, or other secrets. Use appropriate local configuration and keep secret-bearing files out of version control.
- Use Conventional Commits for Git commit messages.
- Ask before performing destructive operations, such as deleting or overwriting user data or project files.
